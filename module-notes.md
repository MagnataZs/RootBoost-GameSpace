# Nota de empacotamento

O arquivo em `dist/` é a base AstralOpt fornecida pelo usuário. Ele é preservado sem alteração de binários para evitar apresentar o APK compilado original como se fosse código-fonte nosso.

A próxima etapa do projeto é substituir gradualmente o painel original por uma implementação RootBoost Game Space própria, em português, mantendo o fluxo visual de seleção de jogos e o botão Jogar.
