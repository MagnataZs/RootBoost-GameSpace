# RootBoost Game Space 0.1.0-alpha

Esta primeira entrega é a fundação pública do projeto novo. O foco não é prometer desempenho imediato; é preservar o estilo de painel escolhido pelo usuário e definir uma base segura para reconstrução.

A release inclui o pacote AstralOpt original fornecido pelo usuário como base de teste. O painel traduzido e a lógica RootBoost própria serão adicionados nas próximas versões, sem modificar binários fechados às cegas.
